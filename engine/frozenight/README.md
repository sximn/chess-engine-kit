# Vendored Frozenight fork

Pinned source, bundled model and licenses are described in ../../docs/PROVENANCE.md. This directory is the engine-development workspace, excluded from the published npm package.

Use the repository-root scripts `engine:build`, `engine:reference`, `engine:notices` and `test:native`; see the root README. Rust 1.90.0 and the wasm32-unknown-unknown target are pinned. Default SDK/package builds use the committed prebuilt WASM and need no Rust installation.
